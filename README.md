# Grupo FOMO · web

Web estática de GRUPO FOMO, S.L. (Barcelona): Mirablau Club, La Rumba Barcelona, Una Noche Tonta y Una Tarde Tonta.

- `index.html`: la página completa (estilos incluidos).
- `img/`: logo, favicon y fotos.
- `vercel.json`: configuración de Vercel. No hace falta build: Vercel sirve los archivos tal cual.
